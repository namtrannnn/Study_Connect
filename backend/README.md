# Social Web Backend

### Planned Chat Improvements

#### Message-level features

- Message type: text, image, mixed, system
- System messages for group actions
- Reply message
- Message reactions
- Edit message
- Edit history
- Revoke message for everyone
- Delete message for current user only
- Pin message

#### Room-level features

- Member nickname in room
- Member joined time
- Member active/left status
- Group admin and superAdmin roles
- Last read message
- Last read time
- Unread message count
- Mute room
- Pin room
- Archive room
- Delete room for current user only

#### Message status features

- Sending
- Sent
- Delivered
- Seen
- Failed

#### Group management features

- Rename group
- Change group avatar
- Add members
- Remove members
- Leave group
- Transfer admin role
- Create system messages for group actions
